## 📊 Dataset di Riferimento

Il progetto utilizza il **DC Arc Fault Dataset**, una raccolta di dati sperimentali progettata per l'addestramento di sistemi di monitoraggio e sicurezza elettrica.

* **Sorgente:** [Kaggle - DC Arc Fault Dataset](https://www.kaggle.com/datasets/yassirsuarez/dc-arc-fault/settings)

* **Descrizione:** Il dataset contiene campionamenti di segnali elettrici (corrente e tensione) acquisiti in sistemi a corrente continua. Include diverse configurazioni di carico e scenari operativi per simulare realisticamente l'innesco di archi elettrici.
